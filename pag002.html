Elementos de formulários

Continuação com demonstração da página de estudos.

Elementos usados para criar formulários, onde o usuário pode digitar, escolher ou enviar informações.

Glossário

  • <form>: elemento com controles interativos que serve para pegar informações do usuário. Pode enviar os dados via method="get" (dados visíveis na URL, usado para buscas) ou method="post" (dados no corpo da requisição, usado para cadastros, login e ações que alteram algo no servidor).
  • <label>: legenda para um item da interface. Usamos junto com o atributo for — quando o for tem o mesmo valor do id do campo, eles se relacionam, facilitando o clique e a acessibilidade para o usuário.
  • <button>: adiciona um botão clicável.
  • <fieldset>: agrupa elementos relacionados de um formulário, geralmente com uma borda visual ao redor.
  • <legend>: título do grupo criado pelo fieldset; aparece encaixado na borda superior dele.
  • <select>: cria uma lista suspensa (dropdown) onde o usuário escolhe uma opção entre várias.
  • <option>: cada opção disponível dentro do select.
  • <textarea>: cria uma caixa de texto com várias linhas, usada para textos mais longos, como comentários ou mensagens.
  • autofocus: faz o campo já começar selecionado (com o cursor pronto para digitar) assim que a página carrega, sem o usuário precisar clicar nele.
  • <input>: usado para criar os controles interativos; o comportamento depende do valor do atributo type. Tendo também os complementos:
    • <name>: identifica o campo quando os dados são enviados ao servidor.
    • <id>: identifica o campo dentro da página, usado para ligar com o for do label.
    • <value>: define o valor inicial (ou o valor enviado, em checkbox/radio).
    • <required>: torna o preenchimento do campo obrigatório antes de enviar o formulário.
    • <min> e <max>: definem o valor mínimo e máximo aceito em campos.
    • <placeholder>: texto de exemplo/dica exibido dentro do campo quando ele está vazio; não é enviado ao servidor.

Exemplo de formulário de Login

Abaixo veremos a demonstração de como um formulário de login básico ficaria, utilizando os elementos do glossário.

Código exemplo: 
<form method="post" action="Seguir o link (ctrl + clique)">
                        <div>
                        <label for="iusu">Usuário:</label>
                        <input
                            type="text"
                            name="usu"
                            id="iusu"
                            minlength="4"
                            maxlength="15"
                            placeholder="Mínimo 4 dígitos"
                            required
                        >
                    </div>
                    <div>
                        <label for="isenha">Senha:</label>
                        <input
                            type="password"
                            name="senha"
                            id="isenha"
                            minlength="8"
                            maxlength="20"
                            placeholder="Mínimo 8 dígitos"
                            required
                        >
                        </div>
                    </form>

Exemplo de formulário de contato

O formulário de contato segue a mesma lógica de login, e visualmente fica deste modo:

Dados para contato
Código exemplo 
<form method="post" action="Seguir o link (ctrl + clique)">
                    <fieldset>
                        <legend>Dados para contato</legend>
                        <div>
                            <label for="imail">E-mail:</label>
                            <input
                                type="email"
                                name="email"
                                id="imail"
                                placeholder="email@provedor.com.br"
                                required
                            >
                        </div>
                        <div>
                            <label for="iphone">Telefone:</label>
                            <input
                                type="tel"
                                name="telefone"
                                id="iphone"
                                placeholder="(00) 00000-0000"
                                required
                            >
                        </div>
                    </fieldset>
                    </form>

Exemplo de Checkbox e Radio

Checkbox e radio são tipos de input usados para marcar opções em vez de digitar texto. O checkbox permite escolher uma ou várias opções ao mesmo tempo, enquanto o radio permite escolher apenas uma entre várias alternativas do mesmo grupo.

Interesses
Está gostando do site?

Adendo:O radio permite escolher apenas uma alternativa desde que todas as opções do radio compartilhem o mesmo nome, o que faz o navegador entender que pertencem ao mesmo conjunto.

Código exemplo: 
<form method="post" action="">
                    <fieldset>
                        <legend>Interesses</legend>
            
                        <input type="checkbox" name="html" id="ihtml">
                        <label for="ihtml">Html</label>
            
                        <input type="checkbox" name="css" id="icss">
                        <label for="icss">CSS</label>
            
                        <input type="checkbox" name="js" id="ijs">
                        <label for="ijs">Javascript</label>
            
                        <input type="checkbox" name="php" id="iphp">
                        <label for="iphp">Php</label>
                    </fieldset>
            
                    <fieldset>
                        <legend>Está gostando do site?</legend>
            
                        <input type="radio" name="resp" value="sim" id="isim" required>
                        <label for="isim">Sim!</label>
            
                        <input type="radio" name="resp" value="demais" id="idemais" required>
                        <label for="idemais">Demais</label>
                    </fieldset>
                </form>

Exemplo de seleção

Nesta seção estão os elementos usados para criar seleções em formulários, formando uma lista suspensa onde o usuário escolhe uma opção sem precisar digitar.

Código exemplo 
<form method="post" action="">
            <label for="iselect">Sistema operacional</label>
            <select name="so" id="iso" required>
                <option value="">Escolha...</option>
                <option value="windows">Windows</option>
                <option value="Mac">MacOS</option>
                <option value="Linux">Linux</option>
            </select>
            
            </form>

Exemplo de text area

A text area é onde o usuário pode enviar algo escrito para o site.

Código exemplo 
<label for="msg">Mensagem:</label>
            <br>
            <textarea name="msg" id="imsg" rows="10" cols="30"></textarea>
            <div>
