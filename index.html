Site para estudos de HTML e CSS

Este site reúne resumos, conceitos e exemplos sobre HTML e CSS, organizados de forma simples e prática. O objetivo é facilitar a revisão dos principais conteúdos e servir como material de apoio para os estudos sobre desenvolvimento web.

O que é HTML?

HTML (HyperText Markup Language) é uma linguagem de marcação (tags) utilizada no desenvolvimento Front-End de sites. Ele é responsável por criar e organizar a estrutura e o conteúdo das páginas, como títulos, textos, imagens, links, listas e formulários.

Glossário do HTML

  • Tags estruturais:
    • <head>: onde ficam as informações do site, como título, configurações e links para outros arquivos.
    • <body>: onde fica todo o conteúdo que aparece na página. Só pode existir um <body> em cada documento.
    • <h1> até <h6>: são os títulos da página. <h1> é o título principal e <h6> é o menor nível de título.
    • <h1> até <h6>: são os títulos da página. <h1> é o título principal e <h6> é o menor nível de título.
    • <p>: cria um parágrafo de texto.
    • <br>: faz uma quebra de linha.
    • <img>: adiciona uma imagem à página.
    • <a>: elemento âncora, cria um link (via atributo href) que leva a outro endereço. Usamos target="_blank" para o link abrir em outra aba, e rel para dar significado ao que o link fará depois de aberto.
    • <div>: caixa genérica de bloco, sem significado próprio. Serve para agrupar outros elementos e organizar o layout, geralmente junto com uma classe CSS.
    • <table>: cria uma tabela, usada para organizar dados em linhas e colunas.
    • <td>: célula de dado dentro de uma linha da tabela.
    • <th>: célula de cabeçalho da tabela; geralmente aparece em negrito e centralizada, indicando o título de uma coluna ou linha.
    • <address>: indica informações de contato do autor ou responsável pela página (como e-mail, endereço, telefone); o texto costuma aparecer em itálico por padrão.
    • <details>: cria um bloco de conteúdo que fica escondido por padrão e aparece quando o usuário clica.
    • <summary>: título/resumo do details, é a parte sempre visível em que o usuário clica para mostrar ou esconder o resto do conteúdo.
  • Tags de formatação de texto:
    • <b> — deixa o texto em negrito (só visual)
    • <i> — deixa o texto em itálico (só visual)
    • <u> — deixa o texto sublinhado (só visual)
    • <strong> — também fica em negrito, mas indica que o conteúdo é importante

O que é CSS?

CSS (Cascading Style Sheets) é a linguagem usada para estilizar páginas HTML: cores, fontes, espaçamento, tamanhos, posicionamento e outros aspectos visuais, separando a aparência da estrutura do conteúdo.

  • padding: espaço interno entre o conteúdo do elemento e sua borda.
  • margin: margem, espaço externo entre o elemento e o que está ao redor dele.
  • border: borda, a linha ao redor do elemento (pode definir espessura, estilo e cor).
  • box-sizing: define como a largura/altura do elemento é calculada; com border-box, padding e borda entram dentro da largura definida, em vez de somados por fora.
  • background-color: cor de fundo do elemento.
  • color: cor das letras/texto.
  • font-family: define a fonte usada no texto.
  • font-weight: grossura da fonte (normal, bold, ou valores numéricos como 400, 700).
  • rem: unidade de medida relativa ao tamanho de fonte definido no elemento raiz (html), útil para manter proporção em toda a página.
  • text-align: alinha o texto dentro do elemento (esquerda, direita, centro, justificado).
  • display: define como o elemento se comporta no layout (bloco, inline, flex, grid, etc).
  • flex: valor de display que transforma o elemento em um container flexível, organizando os filhos em linha ou coluna.
  • flex-direction: define a direção dos itens dentro de um container flex (linha ou coluna).
  • gap: espaço entre os itens dentro de um container flex ou grid.
  • hover: pseudo-classe que aplica um estilo quando o mouse está passando por cima do elemento (sem precisar clicar).
  • width: define a largura do elemento.
  • font-size: define o tamanho da fonte do texto.
  • border-radius: arredonda os cantos da borda do elemento.
  • border-color: define a cor da borda do elemento.
  • cursor: define o formato do cursor do mouse ao passar sobre o elemento (ex: pointer para indicar que é clicável).
  • margin-block: define a margem no eixo vertical (topo e base) de uma vez só.
  • resize: controla se o usuário pode redimensionar o elemento (usado principalmente em textarea); none desativa esse redimensionamento.
